# High-Speed IoT Power Profiling & Battery Estimation

This repository contains a complete hardware and software toolchain for high-resolution power profiling of IoT edge devices. It is designed to measure the energy cost of heavy computational tasks (like matrix multiplication) and calculate real-world battery life projections.

In this setup, an **Arduino Uno** acts as a High-Speed Data Acquisition (DAQ) device to measure the current draw of a **Seeed Studio XIAO nRF52840 Sense** performing intensive CPU loads.

## 📂 Project Structure & Navigation

The project is divided into hardware scripts (C++) and analysis software (Python).

* `power/power.ino`
    * **The DAQ Firmware:** Upload this to the Arduino Uno. It uses the Uno's default 5V reference and a 1-Ohm shunt resistor to measure current at about 100 Hz and outputs the raw `mA` readings over Serial.
* `matrix/matrix.ino`
    * **The Edge Device Firmware:** Upload this to the Seeed XIAO nRF52840. It acts as the "Test Subject," performing heavy 100x100 matrix multiplications in exactly 0.5-second bursts to create measurable "Power Mountains."
* `logger.py`
    * **The High-Speed Logger:** A lightweight Python script that reads the Serial output from the Arduino as fast as possible and saves it to a CSV file with millisecond timestamps. 
* `analysis.py`
    * **The Data Analyzer:** A robust Pandas/SciPy script that reads the CSV, filters noise, detects the "Power Mountains," calculates the exact Energy (in milliJoules) per computation, and projects battery life for CR2032, LiPo, and AA batteries.
* `requirements.txt`
    * Contains the necessary Python dependencies for the software.
* `nrf_high_speed_data.csv`
    * Sample output data generated by the logger.

## 🔌 Hardware Setup

1.  **The Shunt Resistor:** Place a $1\Omega$ resistor in series between the power source and the nRF52840's `3V3` pin.
2.  **The Measurement:** Connect the Arduino Uno's `A0` pin to the "load" side of the shunt resistor, and ensure the Arduino Uno and the nRF52840 share a common Ground (`GND`).
3.  **Reference Voltage:** The Arduino Uno is configured to use its default 5V ADC reference. With a 1Ω shunt, the reading range can represent up to about 5000 mA.
